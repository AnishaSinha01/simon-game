# Simon Game 🎮

A fun memory-based game where players repeat a sequence of colors that increases with each level.

## Features
- Random color sequence generation
- Level progression system
- User input validation
- Game over animation
- High score tracking

## Technologies Used
- HTML
- CSS
- JavaScript

## How to Play
1. Press any key to start
2. Watch the color sequence
3. Repeat the sequence by clicking buttons
4. Game ends if you press the wrong color
